Medium Reliable Delivery

Asset-generation scripts mutate the working tree without reset or verification

Handout by AI/generate_assets.py and the Rydberg atom/attachments/*.py scripts write PNG outputs into the repository at hard-coded paths. Running them changes the working tree, and there is no check that the committed PNGs are current with the scripts that produced them. An agent could regenerate assets, commit, and leave stale or unrelated images in the vault.
